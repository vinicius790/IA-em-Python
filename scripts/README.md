# scripts/

Scripts utilitários de verificação, executados manualmente ou no CI.

- `smoke_test.py`: smoke test rápido da API.
- `run_audit_tests.py`: executa a bateria de testes de auditoria.
- `test_import.py`: valida que os módulos do pacote `app` importam sem erros.

Uso: `python scripts/<nome>.py` a partir da raiz do repositório.
